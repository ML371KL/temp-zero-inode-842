# P_package — пакет изменений слоя решения на одном эталонном движке: ступени, абляции, взаимодействия

Аудит панели «MOEX Radar» (842), вторая волна, 2026-09-02. Агент `P_package`. Данные: `data/panel_prod_daily.csv` (дневная панель прода с честными лагами), `panel_prod_monthly.csv` (композит закрытого месяца, побитово = эталон), `cash_and_tr.csv` (MCFTR, ставка ДР), `cb_decisions.csv` (ключевая по дате решения), `raw_long.csv` (оборот IMOEX для P7). Скрипты: `scripts/P_lib.py` (движок), `P_run.py` (лестница, абляции, чувствительности), `P_stats.py` (бутстреп, своевременность, годовые вклады, «сегодня», плацебо, walk-forward), `P_extra.py` (сверка с рамкой D2, эффект дня после сигнала, ложные входы P5, плацебо «день месяца»), `P_tables.py` (таблицы). Таблицы: `results/P_*.csv`; дневные позиции всех 86 конфигураций — `results/P_positions.csv`.

## Резюме (5 строк)

1. **Движок сверен**: ступень P0 побитово совпадает с правилом панели из A_baseline (`pos_c`, 0 расхождений из 5675 дней), месячный вариант — с `pos_e`; на основном окне 2010-01…2026-08 P0 даёт **17,4 % / Шарп 1,22 / MDD −26,8 %** при исполнении t+1 и **14,6 % / 0,99 / −26,3 %** при t (b&h 9,0 % / 0,42 / −53,5 %, ДР 10,1 %). Все дальнейшие приращения измерены относительно этих чисел на одном и том же коде.
2. **Лестница по Шарпу (t+1 / t), main 2010–2026**: P0 1,22/0,99 → P1 (композит дневной, решение по пятницам, ±0,2) 1,35/1,16 → P2 (+ гистерезис битов) 1,39/1,29 → P3 (+ бит репрайсинга, читается ежедневно) 1,34/1,40 → P4 (+ тренд по MCFTR) 1,35/1,40 → P5 (+ стабилизация) 1,17/1,29; P7 (P2 + вето по обороту) 1,30/1,28. **Устойчивые ступени — P1 и P2**: у P1 знак приращения к P0 положителен во всех пяти окнах при t+1 (p 0,001–0,24) и при t (p=0,005); у P2 приращение к P1 по Шарпу ≈ 0 (−0,03…+0,15 по окнам), но MDD −26,8 → −23,5 % во всех окнах с 2020 годом и сделок 3,7 → 2,9/год. Суммарный эффект P2 к P0: +0,17 Шарпа (p=0,14 при t+1; +0,29, p=0,001 при t), ex-2022 всего +0,05 — половина выигрыша P1 сделана 2022 годом (+12 п.п.).
3. **Бит репрайсинга ожиданий живёт на месячной каденции, а не на дневной.** Читаемый ежедневно (P3, как поставлено в задании) он нейтрален по Шарпу при t+1 (−0,05 к P2, p=0,58), удваивает сделки (2,9 → 7,2/год), режет CAGR на 2,8 п.п. и Шарп над ДР на 0,14; его выигрыш существует только при исполнении в день сигнала (+0,11 при t: день после сигнала −0,28 %). Тот же бит, **читаемый на конце месяца и удерживаемый месяц (P3m, каденция D2)**, даёт 18,4 % / **1,55** / −18,7 % при 4,0 сделки/год: +0,16 к P2 (p=0,12), +0,32 к P0 (p=0,02), плацебо случайных серий p=0,07 (t+1) / 0,04 (t), walk-forward порога×окна +0,28 (p=0,007). Оговорка: конец месяца — 3-я из 21 точки чтения внутри месяца, середина месяца даёт ноль (медиана 1,39 = P2), а над ДР прирост к P2 лишь +0,05 (p=0,34): бит зарабатывает дисперсией (в рынке 42 % вместо 50 %) и двумя эпизодами — март-2015 (+11 п.п.) и март-2020 (+10 п.п.) — против пропущенных ралли 2023 (−18 п.п.) и 2018 (−11 п.п.).
4. **Отвергнуты с числами**: стабилизация как вход в токсичной ячейке (P5: −0,18 к P4, p=0,98; в 2008 три входа, два ложных, −24,5 % за 5 дней; в 2022/2024/2026 на недельной сетке не сработала ни разу — проблему входа не лечит); тренд по MCFTR (±0,01 Шарпа, косметика); ступенчатый вход и трейлинг-стоп (Шарп над ДР −0,12 и −0,20 к P3); вето по обороту поверх P2 при пороге 0,10 (−0,09, p=0,70; плацебо p=0,49), при 0,20 — +0,05 (p=0,27); конструкция D1 на месячном P0 даёт +0,22 (p=0,05, плацебо p=0,06), но walk-forward по порогу её хоронит (−0,06) — порог 0,10 in-sample.
5. **Своевременность**: пакет ускоряет выход (медианный лаг после пика 35,5 дн у P0 → 29 у P2 → 25 у P3m; избегнуто 76 → 83 → 84 % падения; COVID: выход на 34-й день у P0/P1/P2, на 28-й у P3m, избегнуто 39 → 64 %) и **не трогает вход** (медиана 38 → 45–46 дней после дна; гистерезис замедляет возврат на ~7 дней; пропущено 63 дня восстановления 84 → 70 % в среднем при медиане 91 → 90 %). На 01.09.2026 все ступени во флэте: P0 с 29.05 (знак композита), P2 с 22.05, P3m с 30.04 (репрайсинг на конце апреля); ни одна не вошла после дна 17.07.2026.

## Метод

- **Один движок** (`P_lib.run_engine`): автомат позиции {0,1} на дневном календаре IMOEX с 2004-01-06 (первый день с ячейкой). Состояние композита — гистерезис ±thr по значениям, взятым **в дни решения** (P0: закрытый месяц, читается ежедневно = прод; P1+: дневное значение «как compute_core» — 59 закрытых месяцев + сегодняшнее сырьё, z по 60, обрезка ±3 — на последний торговый день недели, W-FRI). Ворота = ячейка (trend, vol, bond) ≠ (0,1,1) на битах прода или на битах с гистерезисом. Выход по воротам и по биту репрайсинга — любым днём; выход по композиту — в день решения; вход по воротам — любым днём (вариант «только в день решения» — чувствительность); возврат после выхода по репрайсингу — в ближайший день решения. Причина каждой смены позиции сохраняется (`P_switches_all.csv`).
- **Ступени** (каждая = предыдущая + одно изменение; параметры взяты из отчётов первой волны, не подбирались): P0 прод; P1 композит дневной / пятница / ±0,2; P2 гистерезис битов (bond вкл. при RGBI dd < −4 %, выкл. при > −3 %; тренд бык при IMOEX > MA200×1,02, медведь при < ×0,98; вола стресс при rv21 > p80 за 756 дн, спокойно при < p60; старт с продового бита); P3 бит-выход expect_stress = 1 при (y1 КБД − ключевая) +0,25 п.п. за 21 торг. день (до 2015 = 0); P3m — тот же бит, читаемый на последний торговый день месяца и удерживаемый до следующего чтения (каденция D2; введён после сверки с D2, см. §Т13a); P4 тренд по MCFTR (MA200 полной доходности, ±2 %); P5 «стабилизация» — второй разрешённый вход в токсичной ячейке при dd252 < −15 % и 21-дн лог-доходности > 0 на недельном срезе, снятие при ret21 < −2 %, знак композита обязателен; P6a/P6b (диагностика) — P3 + ступенчатый вход 50 % на 21 день / трейлинг 8 % с паузой 21 день; P7 — лучшая ступень по Шарпу main t+1 (P2) + вето по «распределительным дням» оборота (dist21 = log(ср. оборот в дни падения / в дни роста за 21 дн) > 0,10, читается в дни решения; признак воспроизведён по коду D1).
- **Абляции** «одно изменение поверх P0» (A_weekly = P1, A_hyst, A_es, A_esm, A_mcftr, A_stab, A_veto ежедневно, A_veto_m помесячно как у D1), **leave-one-out** от P3 (без недельного композита / без гистерезиса / без репрайсинга). **Чувствительности**: P1 — день недели × порог 0,1/0,2/0,3, вход по воротам в день решения, гистерезис по дневному ряду, закрытый месяц по пятницам, дневное решение; P2 — вариант B (RGBI −3 % без гистерезиса), гистерезис по одному биту; P3/P3m — порог 0,10/0,15/0,25/0,35 × окно 10/21 × ключ по дате вступления/решения, возврат сразу, чтение по пятницам; P4 — без гистерезиса; P5 — без композита, dd −20 %, на P3; P7 — порог 0,05/0,10/0,15/0,20 × чтение в день решения/ежедневно, лаг признака 5/10 дней, на P3. Всего **86 конфигураций** правил × 2 исполнения × 3 уровня издержек; плюс 8 конфигураций сверки с рамкой D2, гибридное исполнение, 42 прогона «день месяца», 5×500 плацебо, walk-forward сеток 8+8+4+4.
- **Бэктест**: лонг = MCFTR (`mcftr_ffill`), флэт = mm_rate/252 (ставка на закрытии t−1), издержки 0,2 % за смену (0,1/0,3), исполнение t+1 (основное) и t (коридор). Метрики на месячной сетке NAV (CAGR, вола, Шарп без вычета безрисковой, Шарп избыточной над ДР, MDD по дневному NAV, доля в рынке, сделок/год, доля лет обгона b&h, hit-rate месяцев). Окна: 2010-01…2026-08 (основное), 2004-01-06…2026-08, эры 2010–2021 / 2022-03-24…2024 / 2025–2026-08, ex-2022 (сцепка без календарного 2022), split A 2004–2017 / B 2018–2026-08, дополнительно 2015+ (окно ставочных рядов).
- **Статистика**: ΔШарп — парный стационарный бутстреп месячных лог-доходностей (Politis–Romano, средний блок 12 мес, 2000 повторов), p одностороннее = доля повторов с Δ ≤ 0; отдельно Δ Шарпа над ДР. Плацебо — случайные биты-выходы с той же долей и тем же распределением длин серий вкл/выкл (500 повторов) для P3, P3m, A_esm, P7, A_veto_m; плацебо «день месяца» для месячного чтения бита (k-й торговый день, k=1…20, и последний). Walk-forward порогов — расширяющееся окно с 2004, выбор по Шарпу прошлого, применение в следующем году. Своевременность — правило 7: зигзаг 15 % по IMOEX с 2004 (26 эпизодов, как у A_baseline), лаг выхода после пика, доля избегнутого падения, лаг входа после дна, пропущенная доля первых 63 дней восстановления и роста до следующего пика (по действующей позиции при t+1).

## Выводы

1. **P1 — недельное решение по дневному композиту — эффект настоящий, но меньше, чем в H_weekly, и зависит от исполнения.** При t (как считал H) все пять дней недели и все три порога лучше P0 во всех окнах (среднее по дням +0,11 Шарпа, T6a); при t+1 — только пятница даёт +0,12 (p=0,13), среднее по дням недели +0,03, на ex-2022 не хуже P0 лишь один день из пяти. Причина: P0 при t страдает от «дня после сигнала» (выход по композиту/воротам приходится на день шока, следующий день +1,0…+1,1 %, T13b), а t+1 этот отскок уже забирает — недельная каденция снимает тот же дефект другим способом. Оборот тот же (3,7 против 3,6), MDD тот же (2020: выход на 34-й день у обоих). 2022 год даёт +12 из +23 п.п. суммарного вклада (выход 20.09.2022 перед мобилизацией). Честная оценка: **+0,03…+0,12 при t+1, +0,11…+0,17 при t**; параметры не подбирались (пятница, ±0,2 — из H), но пятница оказалась лучшим днём из пяти, и это надо помнить.
2. **P2 — гистерезис битов — покупает просадку и оборот, не доходность.** К P1: Шарп +0,04 (p=0,32) при t+1, +0,13 (p=0,06) при t; MDD −26,8 → −23,5 % (2010–2021 и split B одинаково); сделок 3,7 → 2,9; CAGR −0,5 п.п. (входы позже на ~7 дней: 2020 — 22-й день вместо 13-го, 2022-07 — 85-й вместо 16-го, 2025-10 — 33-й вместо 13-го). Из трёх битов работает **вола** (p80/p60: S2_vol_only 1,42 > P2 1,39), bond и trend по отдельности ≈ 0; вариант B (RGBI −3 % без гистерезиса) = P2. Это согласуется с F2 (ворота открывает успокоение волы) и с B_timeliness (RGBI −3 % «не хуже»).
3. **P3 (бит репрайсинга ежедневно) как поставлен — не улучшение.** 46 флэт-отрезков медианой 7 дней, полезных 39 %, суммарно −25,7 п.п. лог; 2018 (−20 п.п.) и 2023 (−17 п.п.) — годы ложных тревог; Шарп над ДР 0,60 → 0,46; издержки 0,3 % — Шарп 1,27 (P2 1,37). Весь его эффект — в дне сигнала: доходность MCFTR в день t+1 после ES-выхода −0,28 % (49 % отрицательных), в день t+2 уже +0,22 %; поэтому при t P3 = 1,40 > P2 1,29, а при t+1 1,34 < 1,39. Гибрид «ES-выход в t, остальное в t+1» даёт 1,51 (+0,12 к P2, p=0,20), но над ДР −0,02 — это тайминг одного дня, а не позиционный сигнал. Плацебо случайных серий: p=0,35 (t+1). Walk-forward порога×окна для дневного чтения: +0,10 (p=0,23) при t+1 и −0,01 при t — семья не держится.
4. **P3m (тот же бит на конце месяца) — единственная новая ступень с претензией на значимость, и у неё две честные оговорки.** Числа: main 18,4 % / 1,55 / −18,7 % / 4,0 сделки; к P2 +0,16 (p=0,12; t: +0,15, p=0,12; full +0,09; ex-2022 +0,16; A +0,12, p=0,09; B +0,12), к P0 +0,32 (p=0,02); плацебо серий p=0,07 (t+1) / 0,04 (t) / 0,06 (full); walk-forward порога×окна +0,28 (p=0,007) — выбор гуляет между 0,25/10 и 0,35/10, семья устойчива. Сверка с D2 (T13a): на месячном эталоне 2015+ ES даёт 1,08 → 1,93 — ровно 1,05 → 1,91 у D2; поверх P2 — 1,62 → 1,95, поверх P0 — 1,32 → 1,90. Оговорка 1: **над ДР прирост к P2 лишь +0,05 (p=0,34)** — бит зарабатывает тем, что реже в рынке (42 % против 50 %) в эпоху ставок 15–20 %; по годам P3m − P2 = −8,8 п.п. доходности при +0,16 Шарпа; крупнейшие выигрыши март-2015 (+11,4 п.п.) и март-2020 (+10,5), крупнейшие потери март-2023 (−7,6), июль-2020 (−6,9), сентябрь-2018 (−5,1); 19 отрезков, полезных 32 %. Оговорка 2: **календарь чтения** — при чтении в k-й торговый день месяца (T13d) конец месяца стоит 3-м из 21 (1,55; k=1–2 дают 1,58, k=5–17 — 1,26…1,46 при медиане 1,39 = P2); кластер сильных точек (k=18…4) непрерывен, что похоже на механизм (окно 21 дня, оканчивающееся на рубеже месяца, всегда содержит заседание ЦБ второй половины месяца), но доказать это на 11 годах нельзя. Вывод: P3m — кандидат в **тень с фиксированными параметрами (0,25 / 21 / конец месяца)** и правом на вето через 12 месяцев наблюдения; в решение сейчас — только если владелец готов платить пропущенными ралли (2023) за −5 п.п. просадки.

8. **Что держится на 2020/2022, а что на всей истории** (T8b): P1 − P0 = +23 п.п. всего, +11 без 2022; P2 − P1 = −6 п.п. (−11 без 2020; вклад — просадка, не доходность); P3m − P2 = −9 п.п. ## Ограничения

- Параметры ступеней взяты из первой волны, но сама первая волна их выбирала на той же истории (порог ±0,2 и пятница — из H; пороги гистерезиса — из F2; 0,25/21 — из D2; 0,10 — из D1): p-значения здесь не учитывают этот отбор; в пакете 86 конфигураций + 42 «дня месяца» + 8 рамок D2 — при таком числе один-два результата с p≈0,05 ожидаемы по шуму.
- До 2015 бит репрайсинга = 0 (нет КБД): P3/P3m на 2010–2014 тождественны P2; их «основное окно» фактически 2015–2026 (11,7 года, один цикл ставок, без 2008). Композит до 2015–2016 — одна нога.
- Бутстреп по одной реализации 200/272 месяцев; ex-2022 и эры — описательно (20–34 мес). Плацебо серий сохраняет долю и длины, но не совпадение с рыночной волой; плацебо «день месяца» — 21 сильно коррелированная точка.
- Исполнение: t+1 на закрытии; пользователь, торгующий на открытии t+1, получит между t и t+1. Издержки без проскальзывания в дни шоков (ворота и репрайсинг закрываются в дни −2…−11 %).
- Гистерезис битов стартует с продового бита в первый определённый день (иначе состояние выдумано); вола p60 — скользящий квантиль 756 дней (min 252) по `realized_vol_21` панели; MA200 по MCFTR считана по `mcftr_ffill` (8 протянутых дней).
- Стабилизация в P5 оценена только на недельном срезе с обязательным знаком композита; dd252 и ret21 — по ценовому IMOEX (как в панели).
- Своевременность считана по зигзагу 15 % IMOEX с 26 эпизодами; при лонге на пике у ступеней 5–7 эпизодов — средние лаги выхода иллюстративны.
- Признак оборота D1 воспроизведён по его коду (imoex_value с 2002-11, дни падения по ret1 ≤ 0), но выводы D1 (+0,21 на 272 мес) не переносятся на дневной движок: они относились к месячному P0 без дневных ворот.
