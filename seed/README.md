# seed/ — незаменимые ряды, собранные исследованием

Эти файлы восстановить автоматически нельзя или очень дорого — они получены разбором
первоисточников агентами в ходе исследования (2026-08-11) и служат затравкой стора при
`pipeline/run.py --mode bootstrap`. Дальше пайплайн дополняет их сам.

| файл | что | как добывалось | почему не пересобрать |
|---|---|---|---|
| `orfr_flows.csv` | нетто-покупки акций по 5 категориям участников, 2020-01…2026-07 | текст PDF «Обзора рисков финансовых рынков» ЦБ + **восстановление из векторной графики диаграмм** для месяцев, где числа только на рисунках | часть значений в PDF существует лишь как график; проверено 15+ контрольных точек против текста ЦБ (сходятся до 0,1 млрд) |
| `cb_decisions.csv` | 106 решений ЦБ по ставке 2014–2026 + **консенсус аналитиков накануне** | архив cbr.ru + поиск консенсусов в архивах новостей | консенсус нигде не лежит рядом машиночитаемо; собирался вручную по каждому заседанию |
| `urals_derived.csv` | налоговая цена Urals помесячно 2015–2026 + рублёвая бочка | пресс-релизы Минэка/Минфина и зеркала | старые релизы разбросаны по зеркалам, часть недоступна |
| `cpi_weekly.csv` | 233 недельных принта ИПЦ 2022–2026 | Росстат + inflation-monitor | архив недельных публикаций рассыпан |
| `cpi_derived.csv` | месячный ИПЦ + SAAR (сезонные факторы 2014–2019) | Росстат | производное, но воспроизводить сезонность заново незачем |
| `auctions.csv` | 246 аукционных дней ОФЗ 2021–2026 | minfin.gov.ru + пресса | таблицы Минфина по годам, часть только в новостях |
| `events_registry.csv` | 52 события (налоги/санкции/переговоры/допэмиссии) | ручной сбор с проверкой дат | событийный реестр по определению ручной |

**Формат** — CSV с заголовком; `bootstrap` разбирает их в нормализованные ряды стора
(см. `pipeline/fetch/manual.py` и `docs/CONTRACT.md` §1).

⚠️ Не удалять и не «чистить»: `orfr_flows.csv` и `cb_decisions.csv` — самые дорогие
артефакты проекта. Их копия должна оставаться в git, даже когда стор живёт в R2.
